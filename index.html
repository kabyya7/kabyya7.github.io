BK 매니저

작은 가게를 위한 콘텐츠 게시 도우미 · A posting assistant for small local shops

무엇을 하나요

BK 매니저는 동네 가게 사장님이 텔레그램 단체방에서 쓰는 도우미입니다. 가게가 직접 만든 영상과 사진을 받아 게시 초안을 보여 주고, 사람이 승인 버튼을 누른 뒤에만 그 가게의 유튜브 채널과 인스타그램 계정에 올립니다.

  • 가게 계정 연결: 가게가 Google 로그인 화면에서 직접 허락합니다 (OAuth 기기 코드 방식)
  • 영상 올리기: 승인한 영상 한 편을 그 가게 채널에 올립니다 (YouTube Data API v3, videos.insert)
  • 채널 확인: 연결된 채널 이름을 보여 줍니다 (channels.list)

공식 API만 사용하며, 승인 없이 자동으로 게시하지 않습니다. 첫 사용처는 경기도 용인시 성복동의 반찬가게 「시즈널쿡」입니다.

What it does

BK Manager is a Telegram-based assistant for small local shops. A shop owner sends a video they made; the assistant shows a draft, and only after a person presses “Approve” it uploads that single video to the shop’s own YouTube channel using the official YouTube Data API v3. It never posts without human approval.
