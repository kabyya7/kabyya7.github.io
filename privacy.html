개인정보처리방침

시행일 2026-11-07 · 운영: BK (문의 kabyya7@gmail.com)

1. 이 앱이 쓰는 정보

  • Google 계정 연결 정보: 가게가 허락하면 Google이 주는 연결 열쇠(OAuth 갱신 토큰)를 받습니다.
  • YouTube 채널 정보: 연결된 채널의 이름과 주소(핸들)만 읽어 연결이 맞는지 보여 줍니다.
  • 올릴 영상과 글: 가게가 텔레그램으로 보낸 영상, 제목, 설명. 승인된 것만 그 가게 채널에 올립니다.

시청자 정보, 댓글, 구독자 명단, 결제 정보는 읽지 않습니다.

2. 어떻게 쓰나

오직 가게가 승인한 영상을 그 가게 채널에 올리고, 올린 결과(영상 주소)를 알려 주는 데만 씁니다. 광고, 판매, 다른 서비스로 넘기는 데 쓰지 않습니다.

3. 보관과 보호

  • 연결 열쇠는 운영 서버(AWS Lightsail, 서울)의 접근이 제한된 파일에만 보관하고, 소스 코드 저장소에는 올리지 않습니다.
  • 영상 파일은 올리는 동안만 메모리에서 다루고 따로 저장하지 않습니다. 올린 영상의 ID와 날짜만 기록합니다.
  • 열쇠는 연결을 끊거나 삭제를 요청하면 지웁니다.
  • 가게가 텔레그램으로 보낸 영상과 글은 그 텔레그램 대화방에 남습니다 (텔레그램의 정책을 따릅니다).

4. 다른 곳에 주는지

Google 사용자 데이터를 제3자에게 팔거나 넘기지 않습니다. 법이 요구하는 경우만 예외입니다.

5. 연결 끊기와 삭제

언제든 Google 계정 → 보안 → 타사 앱 액세스(https://security.google.com/settings/security/permissions)에서 「BK 매니저」의 권한을 없앨 수 있습니다. 서버에 남은 정보 삭제는 위 이메일로 요청하면 7일 안에 지웁니다.

6. YouTube와 Google

이 앱은 YouTube API 서비스를 사용합니다. 이 앱을 쓰면 YouTube 서비스 약관에 동의하는 것이며, Google의 정보 처리는 Google 개인정보처리방침을 따릅니다.

Google API에서 받은 정보의 사용과 전달은 Google API 서비스 사용자 데이터 정책(제한적 사용 요건 포함)을 지킵니다.

Privacy Policy (English)

Effective 2026-11-07 · Operator: BK (contact kabyya7@gmail.com)

Data we access

  • An OAuth refresh token issued by Google when the shop authorizes the app.
  • The connected YouTube channel’s title and handle (channels.list), to confirm the right channel.
  • The video, title and description the shop sends to us. Only approved videos are uploaded (videos.insert).

We do not access viewer data, comments, subscriber lists or payment data.

How we use it

Solely to upload videos the shop has approved to the shop’s own channel and report the result. No advertising, no sale, no transfer to other services.

Storage and security

Refresh tokens are stored only in an access-restricted file on our server (AWS Lightsail, Seoul) and never in source code. Video files are processed in memory during upload and not retained; we keep only the uploaded video ID and date. Videos and text the shop sends via Telegram remain in that Telegram chat under Telegram’s policies.

Sharing

We do not sell or share Google user data with third parties, except where required by law.

Revoking access and deletion

You can revoke access at any time via the Google security settings page. To delete data held on our server, email us; we delete it within 7 days.

YouTube and Google

This app uses YouTube API Services. By using it you agree to be bound by the YouTube Terms of Service. See the Google Privacy Policy. Our use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
